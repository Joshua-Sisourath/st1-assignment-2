Part H Reflection

Before using AI, I built the SmartCare appointment prototype using basic Python variables, lists, dictionaries and functions. The program could store a patient name, practitioner name and appoint time, then display the recorded appointments. The AI tutor helped me understand how the booking function works and helped identify limitation such as duplicate bookings, weak input validation and temporary storage. Some AI suggestions could add assumptions, so I compared each suggestion with the SmartCare requirements instead of automatically accepting it. I verified the output by running the code and testing a normal appointment, a blank patient name but still allows some invalid or duplicate information. The engineering work that remained for me was deciding which improvements were actually required, testing the behaviour, checking the code against the case study and making sure I could explain the final code myself.
